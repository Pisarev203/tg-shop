# MSV Shop / Telegram Mini App

В проект добавлены мобильный каталог, варианты товаров, личный кабинет, CRM,
промокоды, накопительные и реферальные скидки, а также расчёт выручки и прибыли.

## Обязательные переменные Amvera

- `API_TOKEN` — токен Telegram-бота.
- `ADMIN_ID` — Telegram ID администратора.
- `WEBAPP_URL` — публичный адрес приложения без `/` в конце.
- `DATABASE_URL` — строка подключения PostgreSQL.
- `ADMIN_WEB_PASSWORD` — новый пароль CRM и старой админки товаров.

Рекомендуемые переменные:

- `ADMIN_WEB_USER` — логин CRM, по умолчанию `admin`.
- `BOT_USERNAME` — имя бота без `@`, нужно для реферальных ссылок.

Если `ADMIN_WEB_PASSWORD` не задан, обе админки закрываются с кодом 503, чтобы
товары нельзя было изменить без авторизации.

## Адреса

- `/` — пользовательское Telegram Mini App.
- `/admin-crm` — CRM, прибыль, графики, заказы, клиенты, товары и промокоды.
- `/admin-web` — прежняя упрощённая админка товаров, теперь также защищённая.
- `/health` — проверка работы приложения.

## Как считается прибыль

Заказ попадает в выручку и прибыль после перевода в статус `Завершён`.

`Прибыль = сумма заказа после скидок − себестоимость всех позиций`.

Себестоимость фиксируется в позиции заказа, поэтому последующее изменение
товара не меняет старую статистику. Для корректного отчёта заполните
себестоимость товаров и вариантов в CRM.

## Скидки

- 3 завершённых заказа — 3%;
- 5 заказов — 5%;
- 10 заказов — 7%;
- 20 заказов — 10%;
- приглашённый клиент получает 5% на первый заказ;
- после первой завершённой покупки друга реферальная скидка пригласившего
  увеличивается на 1%, максимум до 10%;
- промокоды на процент или фиксированную сумму создаются в CRM.

Итоговые цены, скидки, остатки и промокоды всегда проверяются сервером — данные
из браузера не используются как источник цены.
